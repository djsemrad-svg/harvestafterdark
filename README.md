# Harvest Afterdark

A cozy farming and survival game set in a small town after a zombie outbreak. Made with Godot 4.7 and GDScript.

## Play it

1. Open Godot 4.7.
2. Click **Import**, choose this folder's `project.godot`, then click **Import & Edit**.
3. Press **F5** (or the play button at the top right).

## Run the tests

From a terminal in this folder:

```
godot --headless --path . res://tests/test_runner.tscn
```

See `PROJECT_STATE.md` for what is built and what comes next.
